## 📋 功能说明

### 🔐 账号功能
- **学员注册**：填写姓名、学号、手机号、密码完成注册
- **学员登录**：使用学号 + 密码登录系统
- **自动登录**：登录状态本地持久化，刷新不丢失

### 📝 考试功能
- **考试列表**：查看待做考试（进行中）和已完成考试
- **在线答题**：进入考试后显示题目，支持倒计时
- **题目类型**：支持选择题、判断题、填空题、简答题
- **答案提交**：一次性提交所有答案
- **自动批改**：选择题和判断题自动批改，填空题/简答题默认给满分（可后续人工批改）

### 📊 成绩查看
- **总分显示**：查看考试总得分、是否及格
- **逐题详情**：查看每道题的学生答案、正确答案、得分、是否正确
- **解析查看**：查看题目解析（如有）

## 📄 页面说明

### 登录页面 (`/login`)
- 输入学号和密码登录
- 底部有"去注册"链接，跳转到注册页面

### 注册页面 (`/register`)
- 填写姓名、学号、手机号、密码、确认密码
- 注册成功后自动跳转到登录页面

### 首页 (`/home`)
- **待做考试**标签页：显示所有进行中且未完成的考试
- **已完成考试**标签页：显示已提交答案的考试及得分
- 点击考试卡片可进入答题或查看结果

### 答题页面 (`/exam/:id`)
- 进入前弹出考试信息确认（考试名称、时长、总分等）
- 确认后开始答题，显示倒计时
- 按顺序显示题目，根据题型展示不同输入控件：
  - **选择题**：显示选项按钮组
  - **判断题**：显示"对/错"按钮
  - **填空题**：显示文本输入框
  - **简答题**：显示多行文本框
- 倒计时结束自动提交
- 可随时点击"提交答卷"按钮

### 结果页面 (`/result/:id`)
- 显示考试名称、总分、及格线
- 显示得分和是否及格
- 逐题显示：题目内容、学生答案、正确答案、得分、是否正确
- 选择题还会显示选项

## 🔌 API 接口

所有接口通过 Vite 代理转发到后端 `http://localhost:8000`

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/student/register` | 学员注册 |
| POST | `/api/student/login` | 学员登录 |
| POST | `/api/student/logout` | 学员登出 |
| GET | `/api/student/me` | 获取当前学员信息 |
| GET | `/api/student/exams` | 获取考试列表（待做/已完成） |
| GET | `/api/student/exams/{id}/questions` | 获取考试题目（不含答案） |
| POST | `/api/student/exams/{id}/submit` | 提交答案 |
| GET | `/api/student/exams/{id}/result` | 查看考试结果 |

## ⚙️ 配置说明

### Vite 代理配置 (`vite.config.js`)

```javascript
server: {
  port: 3001,
  proxy: {
    '/api': {
      target: 'http://localhost:8000',
      changeOrigin: true
    }
  }
}
```

### Token 认证机制

- 登录成功后，后端返回 UUID Token
- Token 存储在 `localStorage` 中
- 每次 API 请求自动在 `Authorization` Header 中携带 Token
- Token 失效时自动跳转到登录页
